## Dependencies

PolyENU uses **enu**, an exhaustive constitutional-isomer enumeration program distributed as part of the [CombiFF](https://github.com/csms-ethz/CombiFF) project.

PolyENU does not include or redistribute `enu`. Users should obtain and install CombiFF/enu separately from the original repository.

For details on third-party software and licenses, see [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).

### Reference for enu

S. R. Rieder, M. P. Oliveira, S. Riniker, and P. H. Hünenberger,  
"Development of an Open-Source Software for Isomer Enumeration,"  
*Journal of Cheminformatics* **15**, 10 (2023).  
https://doi.org/10.1186/s13321-022-00677-6
