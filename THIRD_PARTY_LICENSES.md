# Third-Party Software

PolyENU uses the following third-party software.

## enu / CombiFF

PolyENU uses **enu**, an exhaustive constitutional-isomer enumeration program distributed as part of the **CombiFF** project.

- Project: CombiFF
- Repository: https://github.com/csms-ethz/CombiFF
- License: BSD 3-Clause License

`enu` is not included in or redistributed with PolyENU. Users should obtain and install CombiFF/enu separately from the original repository.
